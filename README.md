# 📝 To-Do List App

A simple desktop application for managing daily tasks, built with Python and the Flet framework.

## 🚀 Features
* Add new tasks and mark them as completed.
* Auto-save functionality using a `JSON` file (tasks are never lost when you close the app).
* Clean and simple user interface.

## 🛠️ Technologies Used
* **Python**
* **Flet** (for the GUI)
* **JSON** (for data storage)
